## 데이터 설계 단계
개념적 데이터 모델|구현 DBMS에 앞서 업무의 핵심 개체·속성·관계를 사용자 관점으로 표현한다.
논리적 데이터 모델|개념 모델을 관계 스키마 등 선택한 데이터 모델 구조로 구체화하되 물리 저장 방식과는 분리한다.
물리적 데이터 모델|파일 배치·인덱스·자료형·저장 공간 등 실제 DBMS의 구현과 성능 요소를 결정한다.
개념 스키마|데이터베이스 전체의 논리 구조와 제약을 조직 차원에서 통합하여 나타낸다.
외부 스키마|특정 사용자나 응용이 필요로 하는 데이터 부분과 표현을 각 관점에서 정의한다.
내부 스키마|데이터가 실제 저장되는 레코드 형식·파일·접근 경로 등 물리 구조를 기술한다.
## 데이터 독립성과 메타데이터
논리적 데이터 독립성|전체 논리 스키마를 변경해도 사용자 관점이나 응용의 변경을 최소화할 수 있는 성질이다.
물리적 데이터 독립성|저장 파일이나 인덱스 구조가 달라져도 논리적 데이터 접근을 바꾸지 않을 수 있는 성질이다.
데이터 카탈로그|테이블·열·제약·권한 등 DBMS가 관리하는 데이터베이스 구조 정보를 보관한다.
업무 용어 사전|같은 업무 개념에 사용하는 명칭과 의미를 표준화하여 부서별 해석 차이를 줄인다.
도메인 표준|같은 종류의 데이터에 적용할 자료형·길이·허용 값·형식 등을 통일한다.
CRUD 매트릭스|업무 기능별로 어떤 데이터 개체를 생성·조회·수정·삭제하는지 교차 표로 정리한다.
## ER 모델 개체와 속성
강한 개체|다른 개체의 식별자에 의존하지 않고 자신의 속성으로 독립적으로 식별할 수 있는 개체이다.
약한 개체|자신의 부분 식별자만으로는 부족하여 소유 개체의 키와 함께 식별해야 하는 개체이다.
복합 속성|주소를 시·구·도로명으로 나누는 것처럼 여러 하위 요소로 분해할 수 있는 속성이다.
다중값 속성|한 개체에 전화번호 여러 개처럼 같은 종류의 값을 복수로 가질 수 있는 속성이다.
유도 속성|생년월일로 계산한 나이처럼 다른 데이터에서 계산하여 얻을 수 있는 속성이다.
부분 식별자|약한 개체들이 같은 소유 개체 안에서 서로 구별될 수 있도록 하는 속성 집합이다.
## ER 관계 제약
일대일 관계|어느 쪽 개체를 기준으로 보아도 상대편 개체와 최대 하나씩 연결되는 관계이다.
일대다 관계|한쪽 개체 하나에 상대편 여러 개가 연결될 수 있지만 반대쪽에서는 하나에 연결되는 관계이다.
다대다 관계|양쪽 모두 상대편 여러 개와 연결될 수 있어 관계 테이블로 풀어 표현하는 경우가 많다.
전체 참여|어떤 개체 집합의 모든 개체가 해당 관계에 반드시 참여해야 하는 제약이다.
부분 참여|개체 집합 중 해당 관계에 참여하지 않는 개체도 허용하는 제약이다.
재귀 관계|같은 개체 유형 사이에서 관리자와 부하처럼 서로 다른 역할로 연결되는 관계이다.
## 키의 선택과 구조
슈퍼키|튜플을 유일하게 식별하지만 불필요한 속성을 더 포함할 수도 있는 속성 집합이다.
대체키|후보키들 중 기본키로 선택되지 않은 나머지 후보키이다.
복합키|둘 이상의 속성을 함께 사용하여 식별하는 키이다.
대리키|업무 의미를 직접 담기보다 식별 목적으로 별도 생성한 일련번호 같은 인공 키이다.
자연키|업무에서 본래 사용하는 속성 값의 조합을 식별자로 채택한 키이다.
식별자 안정성|기본키를 선정할 때 값이 자주 바뀌지 않아 참조 갱신과 연결 유지 부담이 적은 특성을 고려한다.
## 관계대수 기본 연산
셀렉션|관계대수에서 주어진 조건을 만족하는 튜플을 골라내는 연산이다.
프로젝션|관계대수에서 지정된 속성들만 추출하고 집합 의미에서 중복 튜플을 제거하는 연산이다.
카티션 곱|두 릴레이션의 모든 튜플 조합을 만들어 연결하는 관계대수 연산이다.
합집합|합병 가능한 두 릴레이션 중 어느 한쪽에 속하는 튜플을 모으는 집합 연산이다.
차집합|합병 가능한 두 릴레이션에서 첫 번째에는 있고 두 번째에는 없는 튜플을 구한다.
교집합|합병 가능한 두 릴레이션에 공통으로 속하는 튜플만 구하는 집합 연산이다.
## 관계대수와 집합 의미
세타 조인|두 릴레이션의 카티션 곱에 일반 비교 조건을 적용하여 조합을 고른다.
동등 조인|두 릴레이션의 속성 값이 같다는 등호 조건을 사용하는 조인이다.
자연 조인|같은 이름의 공통 속성 값이 같은 튜플을 결합하고 중복되는 공통 속성을 하나만 남긴다.
디비전|두 번째 관계의 모든 지정 값과 연관되는 첫 번째 관계의 값을 구하는 전칭 조건 연산이다.
합병 가능성|집합 연산을 위해 릴레이션의 차수가 같고 대응 속성 도메인이 호환되어야 하는 조건이다.
릴레이션 집합성|수학적 관계 모델에서는 튜플의 중복이나 튜플의 물리적 순서가 논리 의미를 갖지 않는 성질이다.
## SQL 조회 조건
WHERE|SELECT가 처리할 행을 그룹화하기 전에 개별 행 조건으로 제한하는 절이다.
BETWEEN|하한과 상한을 모두 포함하는 범위 조건을 표현하는 SQL 연산자이다.
IN 목록|값이 지정된 여러 후보 값 중 하나와 일치하는지 검사하는 조건이다.
LIKE 밑줄 패턴|문자열 패턴에서 밑줄 하나가 임의의 문자 하나에 대응하도록 검사한다.
LIKE 퍼센트 패턴|문자열 패턴에서 퍼센트가 길이 0 이상인 임의의 문자열에 대응하도록 검사한다.
괄호에 의한 조건 묶기|AND와 OR의 기본 우선순위에만 의존하지 않고 의도한 논리 결합 순서를 명확히 한다.
## SQL 표현식과 함수
COALESCE|여러 인수 중 NULL이 아닌 첫 값을 반환하여 대체값을 선택하는 SQL 함수이다.
NULLIF|두 인수가 같으면 NULL을 반환하고 다르면 첫 인수를 반환하는 SQL 함수이다.
CASE 표현식|조건이나 값에 따라 서로 다른 결과식을 선택하는 SQL의 조건 분기 표현이다.
CAST|SQL 값의 자료형을 명시적으로 다른 자료형으로 변환하는 표현이다.
UPPER|문자열의 소문자를 대문자로 변환하는 데 사용하는 SQL 문자열 함수이다.
TRIM|문자열의 앞뒤 등 지정 위치에서 공백이나 지정 문자를 제거하는 SQL 함수이다.
## SQL 집계의 차이
COUNT 별표|열 값의 NULL 여부와 관계없이 결과 집합의 행 수를 세는 집계식이다.
COUNT DISTINCT|지정한 표현식에서 NULL을 제외하고 서로 다른 값의 수를 세는 집계식이다.
SUM|NULL이 아닌 숫자 값들을 더한 합계를 구하는 집계 함수이다.
AVG|NULL이 아닌 값들을 대상으로 합계를 그 값의 개수로 나눈 평균을 구하는 집계 함수이다.
GROUP BY|지정한 열이나 표현식 값이 같은 행들을 하나의 집계 그룹으로 묶는다.
집계 없는 빈 그룹 입력|GROUP BY 없는 집계에서 입력 행이 0개여도 COUNT는 0, SUM 등은 NULL이 될 수 있는 SQL 동작이다.
## SQL 조인 보존 방향
LEFT OUTER JOIN|일치하는 오른쪽 행이 없더라도 왼쪽 행을 보존하고 오른쪽 열을 NULL로 채운다.
RIGHT OUTER JOIN|일치하는 왼쪽 행이 없더라도 오른쪽 행을 보존하고 왼쪽 열을 NULL로 채운다.
FULL OUTER JOIN|양쪽 어느 테이블의 행이든 일치 상대가 없어도 보존하는 외부 조인이다.
CROSS JOIN|별도 결합 조건 없이 두 입력의 모든 행 조합을 반환한다.
셀프 조인|같은 테이블에 서로 다른 별칭을 부여하여 자기 자신과 결합한다.
조인 ON 조건|테이블을 결합할 때 어떤 행 조합을 일치로 판단할지 명시하는 절이다.
## SQL 하위 질의
스칼라 하위 질의|하나의 값이 필요한 위치에서 한 행 한 열의 값을 반환하는 하위 질의이다.
상관 하위 질의|바깥 질의의 열을 참조하여 바깥 행의 문맥과 연결된 하위 질의이다.
EXISTS|하위 질의가 한 행 이상 반환하는지를 검사하는 SQL 조건이다.
NOT EXISTS|하위 질의가 아무 행도 반환하지 않는지를 검사하는 SQL 조건이다.
ANY 비교|하위 질의의 비교 대상 값 중 하나 이상에 대해 비교가 참이면 참이 되는 조건이다.
ALL 비교|하위 질의의 모든 비교 대상 값에 대해 비교가 참이어야 참이 되는 조건이다.
## SQL 결과 결합과 순서
UNION ALL|두 질의 결과를 결합하면서 결과 행의 중복을 제거하지 않는다.
UNION|두 질의 결과를 결합하고 중복 결과 행을 제거한다.
INTERSECT|두 질의 결과에 공통으로 존재하는 결과 행을 반환하는 집합 연산자이다.
EXCEPT|첫 번째 질의 결과 중 두 번째 결과에는 없는 행을 반환하는 표준 SQL 집합 연산자이다.
ORDER BY DESC|지정한 정렬 키 값을 내림차순으로 나열하도록 요청한다.
정렬 없는 결과 순서|ORDER BY가 없으면 저장·실행 계획에 보이는 우연한 행 순서를 계약으로 가정해서는 안 되는 성질이다.
## SQL 데이터 변경
INSERT VALUES|명시한 열에 대응하는 값을 지정하여 새 행을 추가하는 SQL 문이다.
INSERT SELECT|다른 질의가 반환한 행들을 대상으로 테이블에 데이터를 추가한다.
UPDATE SET|기존 행 중 조건에 맞는 행의 열 값을 새 값으로 바꾼다.
DELETE WHERE|조건을 만족하는 기존 행을 제거하되 테이블 정의 자체는 남긴다.
조건 없는 UPDATE|WHERE를 쓰지 않아 대상 테이블의 모든 행이 수정 대상이 되는 상황이다.
조건 없는 DELETE|WHERE를 쓰지 않아 대상 테이블의 모든 행이 삭제 대상이 되는 상황이다.
## SQL 스키마 정의
CREATE TABLE|새 테이블의 열·자료형·제약 조건을 선언하여 데이터 구조를 생성한다.
ALTER TABLE|이미 존재하는 테이블의 열이나 제약 같은 정의를 변경한다.
DROP TABLE|테이블 정의 자체를 제거하며 그 데이터도 더는 해당 테이블로 접근할 수 없게 한다.
CREATE VIEW|SELECT 질의를 바탕으로 이름 있는 가상 테이블의 정의를 만든다.
CREATE INDEX|테이블에 별도의 검색 접근 경로를 만들어 조회 성능 개선을 시도한다.
REVOKE|사용자나 역할에 부여했던 데이터베이스 권한을 회수하는 SQL 명령이다.
## SQL 무결성 제약
NOT NULL|해당 열에 값이 없는 NULL을 저장하지 못하도록 제한하는 열 제약이다.
UNIQUE|지정한 열 조합의 값이 중복되지 않도록 제한하며 NULL 처리는 DBMS 규칙도 확인해야 한다.
CHECK|행에 대한 논리 조건을 선언하여 거짓인 경우를 거부하며 NULL에 따른 UNKNOWN은 일반적으로 허용하는 제약이다.
DEFAULT|행 추가 시 값을 생략한 열에 사용할 기본값을 정의하는 절이다.
ON DELETE CASCADE|참조 대상 행이 삭제되면 이를 참조하는 자식 행들도 연쇄 삭제하도록 지정한다.
ON DELETE SET NULL|참조 대상 행이 삭제되면 자식의 외래키 열을 NULL로 바꾸도록 지정하며 NULL 허용이 필요하다.
## 함수 종속 분석
함수 종속|속성 집합 X의 값이 같으면 속성 집합 Y의 값도 항상 같아 X가 Y를 결정하는 관계이다.
완전 함수 종속|Y가 X 전체에 종속하지만 X의 어떤 진부분집합으로도 Y를 결정할 수 없는 관계이다.
부분 함수 종속|복합 결정자의 진부분집합만으로도 종속 속성을 결정할 수 있는 관계이다.
이행적 함수 종속|X가 Y를, Y가 Z를 결정하는 연결을 통해 X가 Z를 간접적으로 결정하는 종속이다.
속성 폐포|주어진 함수 종속 집합 아래에서 어떤 속성 집합으로 결정할 수 있는 모든 속성의 집합이다.
자명한 함수 종속|X에서 Y로의 종속에서 Y가 X의 부분집합이어서 항상 성립하는 종속이다.
## 정규형과 분해
제3정규형|모든 비자명 종속 X→A에서 X가 슈퍼키이거나 A가 주요 속성인 조건을 만족한다.
제4정규형|모든 비자명 다치 종속의 결정자가 슈퍼키가 되어야 하는 정규형이다.
제5정규형|비자명 조인 종속이 후보키에 의해 함의되는 조건을 통해 조인 종속에 따른 중복을 다루는 정규형이다.
무손실 분해|분해한 릴레이션을 다시 조인했을 때 원래 관계를 정확히 복원하고 가짜 튜플이 생기지 않게 한다.
종속성 보존|분해 후 각 릴레이션의 제약을 검사하는 것만으로 원래 함수 종속을 유지할 수 있게 한다.
반정규화|조회 성능 등 검토된 목적을 위해 중복·통합 등을 의도적으로 도입하며 일관성 비용도 고려한다.
## 이상 현상과 분할
삽입 이상|불필요한 다른 정보를 함께 넣지 않으면 원하는 사실을 저장하기 어려운 문제이다.
삭제 이상|어떤 사실을 지우는 과정에서 유지해야 할 별개의 사실까지 함께 사라지는 문제이다.
갱신 이상|같은 사실이 여러 행에 중복되어 일부만 고치면 데이터가 서로 불일치하는 문제이다.
수직 분할|테이블을 열의 집합 기준으로 나누고 필요하면 공통 식별자로 다시 결합한다.
수평 분할|테이블을 행의 조건이나 범위 기준으로 나누되 각 조각은 같은 종류의 열을 갖게 한다.
다치 종속|하나의 결정자에 대해 서로 독립적인 두 속성 집합 값의 조합이 생기는 종속을 나타낸다.
## 트랜잭션 제어
COMMIT|현재 트랜잭션이 수행한 변경을 성공적으로 확정하도록 요청한다.
ROLLBACK|트랜잭션의 변경을 취소하여 확정 전 상태로 되돌리도록 요청한다.
SAVEPOINT|트랜잭션 내부에 부분 롤백 대상으로 사용할 이름 있는 지점을 설정한다.
일관성 속성|트랜잭션 전후 데이터베이스가 정의된 무결성 규칙을 만족하는 유효 상태를 유지하도록 하는 ACID 성질이다.
격리성 속성|동시 실행 트랜잭션들이 서로의 중간 상태를 부적절하게 간섭하지 않도록 하는 ACID 성질이다.
직렬 가능성|병행 실행의 결과가 어떤 순서의 직렬 실행 결과와 동등할 수 있는 성질이다.
## 동시성 이상 현상
반복 불가능 읽기|한 트랜잭션이 같은 행을 다시 읽을 때 다른 트랜잭션의 변경 확정으로 값이 달라진다.
팬텀 읽기|같은 조건의 질의를 다시 실행했을 때 다른 트랜잭션의 삽입·삭제 등으로 조건을 만족하는 행 집합이 달라진다.
갱신 분실|두 트랜잭션이 같은 이전 값을 바탕으로 수정하여 한쪽의 갱신 효과가 다른 쓰기에 덮인다.
쓰기 편향|각 트랜잭션은 서로 다른 행을 수정하지만 함께 보면 여러 행에 걸친 업무 제약이 깨진다.
낙관적 버전 검사|읽은 행의 버전이 여전히 같은지 갱신 조건에 넣어 충돌을 탐지한다.
비관적 동시성 제어|충돌 가능성을 예상하여 데이터를 사용하기 전에 잠금 등으로 동시 접근을 제한한다.
## 격리 수준과 버전
READ UNCOMMITTED|SQL 격리 수준 중 다른 트랜잭션의 미확정 변경을 읽는 것을 허용할 수 있는 가장 낮은 수준이다.
READ COMMITTED|읽는 데이터가 확정되어 있어야 하지만 같은 행을 다시 읽은 값이 달라질 수 있는 격리 수준이다.
REPEATABLE READ|표준 SQL 현상 기준으로 더티 리드와 반복 불가능 읽기를 막지만 팬텀까지 항상 막는 것은 아닌 수준이다.
SERIALIZABLE|동시 실행 결과가 직렬 실행과 동등하도록 보장하는 가장 강한 표준 SQL 격리 수준이다.
MVCC|데이터의 여러 버전을 관리하여 읽기 시점에 맞는 버전을 제공하고 읽기·쓰기 경합을 줄인다.
스냅샷 격리|트랜잭션이 일관된 시점의 스냅샷을 보며 동시 쓰기 충돌을 검사하지만 쓰기 편향이 가능할 수 있다.
## 데이터 잠금
공유 잠금|다른 읽기 잠금과 양립할 수 있지만 일반적으로 배타적 수정 잠금과 충돌하는 잠금이다.
배타 잠금|대상 자원을 수정하기 위해 다른 공유·배타 잠금의 동시 획득을 제한한다.
2단계 잠금|잠금 획득 단계 뒤에 해제 단계를 두고 해제 후 새 잠금을 얻지 않는 프로토콜이다.
엄격 2단계 잠금|특히 배타 잠금을 트랜잭션 종료까지 유지하여 미확정 쓰기를 다른 트랜잭션이 보지 않게 한다.
잠금 단위|행·페이지·테이블처럼 하나의 잠금이 보호하는 데이터 범위를 뜻한다.
잠금 승격|많은 세부 잠금을 더 큰 범위의 잠금으로 바꾸어 관리 부담을 줄이되 동시성이 낮아질 수 있다.
## 교착과 동시성 정책
대기 그래프|어느 트랜잭션이 다른 트랜잭션의 자원을 기다리는지 방향 간선으로 표현한다.
교착 탐지|이미 발생할 수 있는 순환 대기 등을 검사하여 교착 상태를 발견하는 접근이다.
교착 희생자|교착을 풀기 위해 비용 등을 고려해 롤백 대상으로 선택하는 트랜잭션이다.
잠금 획득 순서 통일|여러 트랜잭션이 같은 순서로 자원을 요청하도록 하여 순환 대기 가능성을 줄인다.
타임스탬프 순서 제어|트랜잭션에 부여한 순서 값에 맞춰 충돌 연산을 허용하거나 거부하여 실행 순서를 관리한다.
기아 현상|계속 양보나 재시작만 하면서 어떤 트랜잭션이 오래도록 작업을 완료하지 못하는 현상이다.
## 장애 복구 방식
UNDO|로그 등을 이용하여 확정되지 않은 트랜잭션의 변경 효과를 취소한다.
REDO|로그 등을 이용하여 확정되었지만 데이터 페이지에 반영되지 않은 변경 효과를 다시 적용한다.
체크포인트|복구 시 살펴볼 로그 범위를 줄이기 위해 처리 상태와 필요한 복구 기준 정보를 주기적으로 기록한다.
즉시 갱신|커밋 전에도 데이터 페이지가 갱신될 수 있어 복구 설계에서 미확정 변경 취소를 고려해야 한다.
지연 갱신|트랜잭션 확정 전에는 변경을 실제 데이터베이스 페이지에 적용하지 않는 방식으로 설명되는 복구 접근이다.
미디어 복구|디스크 손상 등 저장 매체 장애 때 백업과 보관 로그 등을 이용하여 데이터를 재구성한다.
## 인덱스 구조
B+ 트리 인덱스|균형 트리의 리프에 검색 키와 데이터 접근 정보를 모으고 리프 연결을 통해 범위 검색을 돕는다.
해시 인덱스|키의 해시값을 이용해 버킷으로 접근하므로 일반적으로 동등 검색에 유리하다.
복합 인덱스|여러 열을 정해진 순서로 결합한 키를 하나의 인덱스로 구성한다.
커버링 인덱스|질의에 필요한 열들이 인덱스에 들어 있어 테이블 본체 접근을 생략할 수 있는 경우를 말한다.
비트맵 인덱스|키 값별로 해당 행 여부를 비트열로 나타내어 조건 조합을 처리하는 인덱스 구조이다.
클러스터링 인덱스|인덱스 키와 데이터 행의 물리적 근접 배치를 연관시켜 범위 접근을 돕는 구조이며 DBMS별 구현을 확인해야 한다.
## 질의 최적화
질의 실행 계획|DBMS가 테이블 접근·조인 순서·정렬 등을 어떤 연산 절차로 수행할지 정한 계획이다.
비용 기반 최적화|행 수·분포·입출력 등 추정 비용을 비교하여 실행 계획을 선택한다.
통계 정보|열 값 분포·행 개수·중복 정도 등을 저장하여 옵티마이저의 크기와 비용 추정에 사용한다.
선택도|검색 조건이 전체 행 중 얼마나 적은 비율의 행을 통과시키는지 나타내는 지표이다.
전체 테이블 스캔|인덱스에 의한 일부 위치 접근 대신 테이블의 모든 행 또는 블록을 확인하는 접근이다.
조건 푸시다운|필터 조건을 데이터 접근 등 더 이른 단계에 적용하여 후속 처리량을 줄이는 최적화이다.
## 저장 구조와 성능
버퍼 풀|디스크 페이지를 메모리에 캐시하여 반복 입출력 비용을 줄이는 DBMS 저장 관리 영역이다.
더티 페이지|메모리에서 수정되어 디스크의 해당 페이지와 내용이 달라진 페이지이다.
페이지 분할|정렬 인덱스 페이지에 새 키를 담을 공간이 부족할 때 내용을 나누어 새 페이지를 연결하는 동작이다.
인덱스 단편화|삭제·분할 등으로 페이지 배치나 빈 공간이 흩어져 접근 효율이 나빠질 수 있는 상태이다.
순차 입출력|연속된 저장 위치를 따라 읽고 써 임의 위치 접근과 다른 비용 특성을 갖는 방식이다.
랜덤 입출력|여러 떨어진 저장 위치를 오가며 접근하여 저장 장치에 따라 추가 지연이 커질 수 있는 방식이다.
## 분산 데이터 구성
데이터 복제|같은 데이터의 사본을 여러 노드에 유지하여 가용성·읽기 분산 등을 도모한다.
샤딩|서로 다른 데이터 부분을 여러 노드로 나누어 저장하여 용량과 부하를 분산한다.
범위 파티셔닝|키 값의 구간별로 행을 나누어 저장하는 분할 방식이다.
해시 파티셔닝|키의 해시 결과에 따라 행을 분배하여 저장 위치를 나눈다.
목록 파티셔닝|지역 코드 등 명시적으로 열거한 값 집합에 따라 행을 구분하여 저장한다.
분산 2단계 커밋|참여 노드들이 준비 여부를 알린 후 조정자가 최종 커밋·중단 결정을 전달하여 원자적 확정을 조정한다.
## 비관계형 데이터 모델
키-값 저장소|고유 키를 이용해 대응 값 덩어리를 조회·저장하는 단순 데이터 모델이다.
문서 데이터베이스|JSON 유사 문서 단위로 중첩 구조와 다양한 필드를 저장·조회하는 데이터 모델이다.
와이드 컬럼 저장소|행 키와 열 패밀리 등을 중심으로 넓고 유연한 열 구조를 다루는 분산 저장 모델이다.
그래프 데이터베이스|정점과 간선 및 속성을 중심으로 관계를 저장하고 연결 탐색을 지원한다.
최종적 일관성|새 갱신이 더 없고 복제가 계속 진행되면 여러 사본의 값이 결국 수렴하는 보장이다.
문서 임베딩 모델링|함께 읽는 관련 데이터를 별도 참조 대신 상위 문서 내부에 넣어 조회를 단순화한다.
