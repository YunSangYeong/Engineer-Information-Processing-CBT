## C 자료형과 선언
sizeof 연산자|C에서 객체나 자료형이 차지하는 크기를 char 단위로 구하며 결과 자료형은 size_t이다.
char의 sizeof|C에서 한 char가 차지하는 저장 단위의 수는 정의상 1이지만 그 단위가 항상 8비트라고 단정할 수는 없다.
unsigned 정수의 범위 초과|C에서 부호 없는 정수의 산술은 해당 자료형의 표현 범위 크기를 법으로 하는 모듈러 연산으로 정의된다.
signed 정수 오버플로|C에서 부호 있는 정수 산술 결과가 표현 범위를 넘으면 일반적으로 정의되지 않은 동작에 해당한다.
const 한정자|C에서 그 한정자를 통해 접근한 객체를 변경하지 못하도록 형식에 읽기 제한을 표현한다.
typedef|C에서 기존 자료형에 새 별칭 이름을 부여하며 독립적인 새 자료형을 만드는 것은 아니다.
## C 연산과 흐름
후위 증가|C에서 x++는 식의 값으로 증가 전 값을 사용하고 x 자체는 1 증가시키는 연산이다.
전위 증가|C에서 ++x는 x를 1 증가시킨 뒤 증가된 값을 식의 값으로 사용하는 연산이다.
논리 AND 단락|C에서 &&의 왼쪽 피연산자가 거짓이면 오른쪽 피연산자를 평가하지 않는다.
논리 OR 단락|C에서 두 조건의 논리합을 구할 때 왼쪽이 참이면 오른쪽 조건을 평가하지 않는다.
break 문|C에서 가장 가까운 반복문 또는 switch의 실행을 종료하고 그 뒤로 이동한다.
continue 문|C에서 현재 반복의 나머지 본문을 건너뛰고 해당 반복문의 다음 반복 진행 단계로 이동한다.
## C 포인터와 배열
주소 연산자|C에서 &x처럼 객체의 메모리 주소를 얻는 데 사용하는 단항 연산자이다.
간접 참조|C에서 유효한 포인터 p에 대해 *p로 그 포인터가 가리키는 객체에 접근한다.
널 포인터|C에서 어떤 유효 객체나 함수를 가리키지 않음을 나타내는 포인터 값이다.
배열 포인터 산술|C에서 int를 가리키는 p에 1을 더하면 같은 배열 안에서 다음 int 원소 위치로 이동한다.
배열 매개변수 조정|C에서 함수 매개변수의 int a[] 선언은 포인터 매개변수로 조정되어 배열 전체가 값 복사되는 것은 아니다.
문자열 널 종료|C 문자열에서 문자 코드 0인 종단 문자가 문자열의 끝을 나타낸다.
## C 동적 메모리와 파일
malloc|C에서 요청한 크기의 동적 저장 공간을 할당하되 그 내용을 0으로 초기화한다고 보장하지 않는 함수이다.
calloc|C에서 여러 요소를 위한 동적 저장 공간을 할당하고 모든 비트를 0으로 초기화하는 함수이다.
realloc|C에서 기존 동적 할당 블록의 크기 변경을 시도하며 저장 위치가 바뀔 수 있는 함수이다.
free|C에서 동적으로 할당받은 블록을 더는 사용하지 않을 때 해제하는 함수이다.
fopen|C 표준 입출력에서 경로와 모드를 지정하여 파일 스트림을 여는 함수이다.
fclose|C 표준 입출력에서 열린 스트림을 닫고 관련 자원을 정리하는 함수이다.
## C 함수와 수명
값 전달|C에서 매개변수는 호출자가 준 값의 복사본을 받으므로 단순 매개변수 대입만으로 호출자 변수가 바뀌지 않는다.
지역 정적 변수|C에서 함수 안에 static으로 선언하면 블록 접근 범위와 별개로 실행 전체 동안 저장 수명을 유지한다.
extern 선언|C에서 다른 번역 단위 등에서 정의된 외부 연결 이름을 참조하는 선언에 사용한다.
댕글링 포인터|가리키던 객체의 수명이 끝나거나 저장 공간이 해제된 후에도 남아 있는 포인터이다.
함수 포인터|C에서 함수의 주소를 저장하고 그 형식에 맞는 함수를 간접 호출할 수 있게 한다.
구조체 멤버 접근|C에서 구조체 객체 s의 멤버는 s.x, 구조체 포인터 p의 멤버는 p->x처럼 접근한다.
## Java 타입과 객체
JVM|Java 바이트코드를 실행하고 메모리·클래스 로딩 등 실행 환경을 제공하는 가상 머신이다.
Java 오버로딩|같은 이름을 쓰되 매개변수 목록이 다른 여러 메서드를 선언하는 기법이다.
Java 생성자|새 인스턴스를 초기화할 때 호출되며 클래스와 같은 이름을 쓰고 반환형을 선언하지 않는다.
this 참조|Java 인스턴스 메서드나 생성자에서 현재 객체 자신을 가리키는 참조이다.
super 참조|Java 하위 클래스에서 상위 클래스의 멤버나 생성자에 접근하는 데 사용하는 키워드이다.
Java abstract 클래스|그 자체로 직접 인스턴스화할 수 없고 하위 클래스의 구현을 위한 추상 메서드 등을 포함할 수 있다.
## Java 접근과 한정
private 접근|Java 클래스의 멤버를 그 클래스 내부 중심의 제한된 접근 범위로 숨기는 접근 제어자이다.
package-private 접근|Java에서 접근 제어자를 쓰지 않은 최상위 클래스나 일반 멤버가 같은 패키지에서 접근 가능하도록 하는 기본 범위이다.
public 접근|Java에서 다른 패키지 등 외부에서도 형식과 모듈 가시성 제약 안에서 접근할 수 있도록 공개한다.
protected 접근|Java에서 같은 패키지와 정해진 규칙을 만족하는 하위 클래스 코드의 접근을 허용한다.
static 멤버|Java에서 특정 인스턴스가 아니라 클래스에 속하여 공유되는 필드나 메서드이다.
final 변수|Java에서 변수에 한 번 대입한 뒤 다른 값으로 다시 대입할 수 없게 하되 참조 대상 객체까지 불변으로 만들지는 않는다.
## Java 라이브러리와 예외
String 불변성|Java 문자열 객체 자체의 내용은 생성 후 바뀌지 않아 수정처럼 보이는 연산이 새 문자열을 만들 수 있다.
StringBuilder|Java에서 같은 가변 문자 시퀀스에 내용을 반복 추가·수정할 때 사용하는 클래스이다.
equals 비교|Java에서 클래스가 정의한 논리적 동등성 규칙에 따라 두 객체가 같은지 검사하는 메서드이다.
참조의 == 비교|Java에서 객체 참조 두 개가 동일 객체를 가리키는지 또는 둘 다 null인지 비교한다.
검사 예외|Java에서 호출자가 처리하거나 throws로 선언하도록 컴파일러가 확인하는 예외 범주이다.
try-with-resources|Java에서 AutoCloseable 자원을 선언하여 블록 종료 시 자동으로 닫도록 하는 구문이다.

TreeSet|Java에서 비교 순서에 따라 원소를 정렬해 유지하는 집합 구현이다.

PriorityQueue|Java에서 기본적으로 자연 순서 등에 따른 우선 원소를 먼저 꺼낼 수 있게 하는 큐 구현이다.

리스트 append|Python 리스트의 끝에 전달한 객체 하나를 하나의 원소로 추가하는 메서드이다.

## 운영체제 서비스
시스템 호출|사용자 프로그램이 커널의 파일·프로세스·장치 등 서비스를 요청하는 정해진 진입 방식이다.
커널 모드|특권 명령과 보호 자원 접근이 허용되는 운영체제 실행 모드이다.
사용자 모드|응용이 보호된 커널 자원에 직접 접근하지 못하도록 제한된 실행 모드이다.
인터럽트|하드웨어 등의 사건이 CPU의 현재 실행 흐름을 잠시 중단시키고 처리 루틴으로 제어를 넘기게 한다.
트랩|예외나 시스템 호출 등 현재 실행과 연관된 원인으로 발생하는 동기적 제어 이전을 가리킨다.
문맥 교환|CPU가 실행 대상을 바꿀 때 레지스터 등 기존 실행 문맥을 저장하고 다음 문맥을 복구한다.
## 프로세스 상태와 제어
준비 상태|CPU를 받으면 실행할 수 있지만 아직 스케줄러의 선택을 기다리는 프로세스 상태이다.
실행 상태|CPU를 할당받아 실제 명령을 수행 중인 프로세스 상태이다.
대기 상태|입출력 완료나 특정 사건을 기다려 CPU만 받아서는 당장 진행할 수 없는 상태이다.
PCB|프로세스 식별자·상태·문맥·관리 정보 등을 보관하는 운영체제의 프로세스 제어 자료구조이다.
좀비 프로세스|자식 프로세스가 종료되었으나 부모가 종료 상태를 수거하지 않아 종료 정보가 남은 상태이다.
fork|Unix 계열에서 현재 프로세스를 바탕으로 자식 프로세스를 생성하는 시스템 호출이다.
## CPU 스케줄링
FCFS|준비 큐에 먼저 들어온 프로세스를 먼저 실행하는 기본 비선점 스케줄링 방식이다.
SJF|다음 CPU 버스트 시간이 가장 짧은 작업을 먼저 고르는 비선점 방식으로 긴 작업 기아 가능성을 고려한다.
SRTF|남은 실행 시간이 더 짧은 프로세스가 도착하면 현재 작업을 선점할 수 있는 최단 잔여 시간 방식이다.
우선순위 스케줄링|프로세스에 부여된 중요도 순서에 따라 실행 대상을 선택한다.
에이징|오래 기다린 작업의 우선순위를 점진적으로 올려 기아를 줄이는 기법이다.
다단계 피드백 큐|실행 행동과 대기 상황 등에 따라 프로세스를 서로 다른 우선순위 큐 사이로 이동시킨다.

뮤텍스|일반적으로 소유권을 가진 하나의 실행 흐름만 공유 자원의 임계 구역에 들어가도록 하는 잠금이다.
세마포어|정수 카운터와 대기·신호 연산으로 여러 자원 접근이나 실행 순서를 제어하는 동기화 도구이다.
이진 세마포어|가용 상태를 두 값으로 관리하며 카운팅 세마포어와 달리 하나의 신호 상태만 표현한다.
조건 변수|공유 상태의 특정 조건이 충족될 때까지 락과 함께 대기하고 알림으로 재확인하게 하는 도구이다.
모니터|공유 데이터와 연산을 묶고 상호 배제 및 조건 대기를 언어·런타임 구조로 제공하는 동기화 추상화이다.
스핀락|잠금을 얻을 때까지 반복해서 상태를 확인하며 CPU를 사용하는 대기 방식의 잠금이다.
## 교착 대응
교착 예방|상호 배제·점유 대기·비선점·순환 대기 중 적어도 하나가 성립하지 않도록 구조를 제한한다.
교착 회피|자원 요청을 허용하기 전에 이후에도 안전한 실행 순서가 가능한지 판단한다.
은행원 알고리즘|각 프로세스의 최대 자원 요구를 이용해 요청 승인 후 안전 상태가 유지되는지 검사한다.
안전 상태|각 프로세스가 필요한 자원을 받아 종료할 수 있는 적어도 하나의 완료 순서가 존재하는 상태이다.
교착 회복|이미 교착에 빠진 경우 프로세스 종료나 자원 회수 등으로 상태를 풀어내는 대응이다.
기아와 교착의 차이|한 작업이 선택받지 못해 무한정 기다려도 전체가 서로 자원을 기다리는 순환 상태일 필요는 없다는 구분이다.
## 메모리 배치
내부 단편화|할당한 블록 안에서 요청 크기를 초과한 부분이 사용되지 않고 남는 공간 낭비이다.
외부 단편화|전체 빈 공간은 충분해도 연속된 큰 빈 구간이 부족하도록 빈 공간이 흩어진 상태이다.
최초 적합|가변 크기 빈 공간 목록에서 요청을 수용할 수 있는 첫 구간을 선택한다.
최적 적합|요청을 수용할 수 있는 빈 구간 중 남는 공간이 가장 작은 구간을 선택한다.
최악 적합|사용 가능한 빈 구간 중 가장 큰 곳에 요청을 배치한다.
세그멘테이션|프로그램의 코드·데이터 같은 논리 단위를 가변 길이 영역으로 나누어 주소 공간을 관리한다.
## 가상 기억장치 세부
페이지 테이블|가상 페이지 번호와 물리 프레임 등 주소 변환 정보를 연결하여 관리한다.
TLB|최근 사용한 페이지 주소 변환 결과를 캐시하여 페이지 테이블 접근을 줄이는 고속 버퍼이다.
요구 페이징|페이지를 미리 전부 적재하지 않고 실제 참조할 때 필요한 페이지를 가져온다.
LRU 페이지 교체|가장 오랫동안 참조되지 않은 페이지를 교체 대상으로 선택한다.
FIFO 페이지 교체|주기억장치에 들어온 지 가장 오래된 페이지를 교체 대상으로 선택한다.
스래싱|작업이 사용할 프레임이 부족하여 유용한 실행보다 페이지 교체에 대부분의 시간을 쓰는 상태이다.
## 파일 시스템 구조
아이노드|Unix 계열 파일 시스템에서 파일의 속성과 데이터 블록 위치 등을 관리하는 자료구조이다.
디렉터리 엔트리|파일 이름을 해당 파일의 관리 정보나 식별자에 연결하는 항목이다.
하드 링크|같은 파일의 관리 객체를 다른 디렉터리 이름에서도 참조하게 하는 연결이다.
심볼릭 링크|다른 경로 문자열을 내용으로 보관하고 경로 해석 때 그 대상으로 연결하는 특별 파일이다.
절대 경로|파일 시스템의 루트에서 시작하여 대상 위치를 지정하는 경로이다.
상대 경로|현재 작업 디렉터리 같은 기준 위치로부터 대상 위치를 지정하는 경로이다.
## 전송과 교환 방식
회선 교환|통신 전에 전용 경로 자원을 설정하고 연결 동안 유지하는 교환 방식이다.
패킷 교환|데이터를 작은 전송 단위로 나누고 네트워크에서 자원을 공유하며 전달하는 방식이다.
데이터그램 방식|각 패킷이 독립적으로 주소를 갖고 전달되어 다른 경로나 순서로 도착할 수 있는 방식이다.
가상 회선 방식|논리적 연결을 미리 설정하고 패킷들을 그 연결 식별자에 따라 전달하는 방식이다.
단방향 통신|정보가 한 방향으로만 전송되는 통신 형태이다.
전이중 통신|양쪽이 동시에 송신과 수신을 수행할 수 있는 통신 형태이다.
## 계층별 전달 단위
비트 전달|OSI 물리 계층이 전기·광·무선 신호 등을 통해 다루는 기본적인 정보 전달 관점이다.
이더넷 프레임|데이터 링크 계층에서 MAC 주소·페이로드·오류 검출 정보 등을 담는 전송 단위이다.
IP 패킷|네트워크 간 라우팅을 위해 논리 주소 등을 헤더에 포함하는 인터넷 계층 데이터 단위이다.
TCP 세그먼트|전송 계층에서 순서 번호·확인 응답·포트 등을 갖는 TCP의 데이터 단위이다.
포트 번호|같은 호스트에서 서로 다른 전송 계층 통신 종단이나 서비스를 구분하는 번호이다.
캡슐화|상위 계층 데이터에 하위 계층의 헤더 등을 붙여 전송 형식으로 감싸는 과정이다.
## 로컬 네트워크 장비
허브|받은 물리 신호를 여러 포트로 반복 전달하며 MAC 주소에 따라 프레임을 선택 전달하지 않는 장비이다.
이더넷 스위치|MAC 주소 학습 표에 따라 프레임의 출력 포트를 선택하는 데이터 링크 계층 장비이다.
라우터|서로 다른 IP 네트워크 사이에서 목적지 주소와 라우팅 표에 따라 패킷을 전달하는 장비이다.
ARP|IPv4 로컬 네트워크에서 다음 홉 IP 주소에 대응하는 링크 계층 주소를 알아내는 프로토콜이다.
기본 게이트웨이|더 구체적인 경로가 없을 때 외부 네트워크로 패킷을 보내도록 설정한 다음 홉이다.
브로드캐스트 도메인|링크 계층 브로드캐스트 프레임이 전달되는 범위로 라우터 등에서 보통 경계가 나뉜다.
## IP 주소와 분할
서브넷 마스크|IPv4 주소에서 네트워크 접두부와 호스트 부분의 경계를 나타내는 비트 마스크이다.
CIDR 접두 길이|IP 주소 뒤의 /숫자로 네트워크 접두부의 비트 수를 표현하는 방식이다.
사설 IPv4 주소|내부 네트워크용으로 예약되어 공용 인터넷에서 직접 라우팅하는 주소로 사용하지 않는 범위이다.
루프백 주소|호스트가 자기 자신과 통신하는 논리 인터페이스에 사용하며 IPv4에서는 127.0.0.0/8이 해당한다.
NAT|네트워크 경계에서 패킷의 IP 주소 등을 다른 주소로 변환하여 전달한다.
PAT|여러 내부 연결을 하나의 외부 주소 등으로 구분하기 위해 포트 번호도 함께 변환한다.
## 인터넷 제어와 라우팅
ICMP|도달 불가나 시간 초과 등 IP 전달과 관련한 제어·오류 정보를 전달하는 프로토콜이다.
DHCP|호스트에 IP 주소·마스크·게이트웨이 등 네트워크 설정을 임대 방식으로 제공한다.
거리 벡터 라우팅|이웃이 알려 주는 목적지별 거리 정보를 이용해 자신의 경로 정보를 갱신하는 방식이다.
링크 상태 라우팅|연결 상태 정보를 공유하여 네트워크 토폴로지를 구성하고 경로를 계산하는 방식이다.
OSPF|링크 상태 정보를 사용하는 대표적인 내부 게이트웨이 라우팅 프로토콜이다.
BGP|자율 시스템 사이의 경로 정보를 교환하며 경로 속성과 정책을 반영하는 라우팅 프로토콜이다.
## 신뢰 전송과 흐름
TCP 3방향 핸드셰이크|SYN·SYN-ACK·ACK 교환으로 순서 번호와 연결 상태를 동기화하며 연결을 설정한다.
TCP 확인 응답|수신한 데이터에 대한 다음 기대 순서 등을 알려 송신 측이 전달 진행을 판단하도록 한다.
TCP 재전송 타이머|정해진 시간 동안 적절한 확인 응답을 받지 못하면 손실로 판단해 다시 전송하도록 한다.
TCP 흐름 제어|수신자가 처리할 수 있는 여유 범위를 알려 수신 버퍼를 넘지 않게 송신량을 조절한다.
TCP 혼잡 제어|네트워크의 혼잡 징후에 맞춰 전송량을 조절하여 경로 과부하를 완화한다.
슬라이딩 윈도|한 번에 확인을 기다리며 보낼 수 있는 데이터 범위를 이동시켜 연속 전송 효율을 높인다.
## 응용 프로토콜
HTTP GET|웹 자원의 표현을 조회하는 메서드로 정의상 서버 상태 변경을 의도하지 않는 안전 메서드이다.
HTTP POST|대상 자원에 표현을 제출하여 생성·처리 등을 요청하며 일반적으로 멱등성이 자동 보장되지는 않는 메서드이다.
SMTP|메일 서버 사이의 전송 등 전자우편을 보내는 데 사용하는 응용 프로토콜이다.
IMAP|서버의 메일함 상태를 유지·동기화하며 메시지를 조회·관리하는 전자우편 접근 프로토콜이다.
FTP|파일 전송을 위한 제어 연결과 데이터 연결을 구분하는 전통적인 응용 프로토콜이다.
NTP|네트워크를 통해 컴퓨터의 시각을 동기화하는 데 사용하는 프로토콜이다.
## 네트워크 오류와 도구
ping|ICMP Echo 요청과 응답 등을 이용하여 도달성과 왕복 지연을 살펴보는 진단 도구이다.
traceroute|TTL 또는 Hop Limit을 바꾸어 경로의 중간 홉 응답을 관찰하는 진단 도구이다.
패킷 캡처|네트워크 인터페이스의 프레임·패킷을 수집하여 프로토콜과 통신 문제를 분석한다.
MTU|한 링크에서 일반적으로 한 번에 전송할 수 있는 네트워크 계층 패킷의 최대 크기이다.
단편화|네트워크에서 패킷이 허용 크기보다 클 때 여러 작은 조각으로 나누는 처리이며 IP 버전에 따라 주체가 다르다.
체크섬|전달 중 데이터 오류를 탐지하기 위해 계산·비교하는 값으로 암호학적 위변조 방지를 대신하지 않는다.
## 프로세스 사이 통신
익명 파이프|Unix 계열에서 파일 디스크립터로 연결된 바이트 스트림을 만들며 흔히 부모·자식 사이 전달에 사용한다.
이름 있는 파이프|파일 시스템 경로를 가진 FIFO를 통해 미리 부모·자식 관계가 없는 프로세스들도 통신하게 한다.
공유 메모리 IPC|여러 프로세스가 같은 물리 메모리 영역을 매핑하여 데이터를 주고받되 별도 동기화가 필요하다.
메시지 큐 IPC|프로세스가 구분된 메시지 단위를 운영체제의 큐에 넣고 다른 프로세스가 수신하는 방식이다.
시그널|Unix 계열에서 특정 사건을 프로세스에 비동기적으로 알리는 제한적인 통지 메커니즘이다.
Unix 도메인 소켓|같은 호스트 내 프로세스들이 로컬 주소 체계로 양방향 소켓 통신을 하도록 한다.
